A wireless earbuds roast aimed at the one thing nobody else complains about: the lone "battery low" chime that is always delivered mid-sentence, on a call, precisely too late to act on. Not a battery-life rant and not a "they fall out" gag — the gripe is the warning itself, a heads-up engineered to arrive after it could ever help. One line, standard-library Python.

## Run it

```sh
python3 main.py
```
